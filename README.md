# lastorders.dev

The public pages and files of the Last Orders app, on GitHub Pages at https://lastorders.dev.

- `index.md`: the home page.
- `pubs/pubs.db`: the UK pub list (SQLite). `pubs/manifest.json` gives its date, size and SHA-256 sum. The app downloads the file only when the sum matches.
